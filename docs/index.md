# Lantern

An open-source, Aladdin-style platform for cross-asset factor risk, scenario simulation and
systematic factor investing.

- **[Interactive sample risk report](demo/lantern_report.html)**: a $10m multi-asset portfolio
  on live data, covering risk decomposition, VaR and expected shortfall, scenarios, the bubble
  monitor and factor timing.
- [Methodology](methodology.md): the math behind every model.
- [What Aladdin does, from public sources](aladdin_research.md): the research that shaped the
  design.
- [Source code on GitHub](https://github.com/Raymondli073/lantern-risk)
